create the simple rag application 
1. input only text file
2. convert into chunks
3. convert chunks into embeddings 
4. store the embeddings into local faiss vecotrdb
5. implemnet cosine similarty search and semantic search for retrival
6. use retrival @web https://docs.langchain.com/oss/python/langchain/retrieval
7. take input as question from the user
8. use various prompt template for input to llm
9. The prompt template @web https://python.langchain.com/docs/concepts/prompt_templates/
10. use langchain-groq openai oss opensource model.
11. pass the prompt to llm to retrieval of the answer

if 'message_history' not in st.session_state:
    st.session_state['message_history'] = []

# loading the conversation history
for message in st.session_state['message_history']:
    with st.chat_message(message['role']):
        st.text(message['content'])

user_input = st.chat_input('Type here')

if user_input:

    # first add the message to message_history
    st.session_state['message_history'].append({'role': 'user', 'content': user_input})
    with st.chat_message('user'):
        st.text(user_input)

    response = chatbot.invoke({'messages': [HumanMessage(content=user_input)]}, config=CONFIG)
    
    ai_message = response['messages'][-1].content

        st.text(ai_message)
